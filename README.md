## Como rodar na máquina

- git clone <https://github.com/NatalyyRodrigues/Bicicletas_Compartilhadas>

- cd Bicicletas_Compartilhadas

- python -m venv .venv

- .venv\Scripts\activate

- pip install -r requirements.txt
- uvicorn main:app --reload
